## epsh engine: dead code (DSLP-17)

The strict scan above enabled `dead_code` and `unreachable_pub`; it reported 0 `dead_code` diagnostics in `crates/epsh/src/`. All 25 `unreachable_pub` diagnostics sit inside `pub(crate)` modules (`crates/epsh/src/signal.rs`: 6, `crates/epsh/src/sys.rs`: 18, `crates/epsh/src/builtins.rs::exec`: 1); workspace search confirms every one of those 25 items has active internal callers. Retain them as visibility-only warnings bounded by their `pub(crate)` modules. A workspace search across `src/`, `crates/`, `tests/`, `examples/`, and `benches/` found 6 public API items referenced only at their definitions (`bad_interpreter_message`, `set_redirect_open_handler_in_children`, `set_command_argv_policy_in_children`, `set_external_dispatcher_in_children`, `parse_word_parts_bytes`, `arg0_shell`). All 6 belong to documented public embedder/parser/variable families; per campaign policy, public API removals are owner walk-backs rather than silent cuts, so all are retained.

Debloat read: `Shell` (`crates/epsh/src/eval.rs`) owns per-instance state and execution, `SavedRedirections` (`crates/epsh/src/redirect.rs`) owns descriptor backup/restore, `Registered<T>` (`crates/epsh/src/callback.rs`) enforces process-bound callback safety, and `ShellBytes` (`crates/epsh/src/shell_bytes.rs`) + `encoding.rs` separate raw OS bytes from UTF-8 syntax. No behavior-preserving cut was established; no walk-back is proposed. Needs environment: `cargo-machete` and `cargo-udeps` are unavailable, so automated dependency liveness was not run; manual inspection confirms all `crates/epsh/Cargo.toml` dependencies (`libc`, `rustc-hash`, `rustix`, dev `tempfile`, `regex-lite`) are imported in `crates/epsh/`.
